# Changelog

## 1.1.0

- Apply Liquid Glass to the peeking sidebar opened from the navigation rail.
- Unify floating menus, listboxes, tooltips, dialogs, and hover-card materials.
- Clear opaque neutral layout fills inside floating surfaces while preserving
  native controls, text opacity, and hit targets.
- Keep search dialogs rounded and use additional blur for readable content.
- Observe sidebar and popup state changes; restore native materials when
  Liquid Glass is disabled. Existing settings and profiles are retained.

## 1.0.0

- Continuous acrylic window, separate workspace/composer transparency, and
  live appearance controls.
- Glass settings panels, menus, tooltips, dialogs, and hover popovers.
- English customization controls and documentation.
- Compatibility-checked local installation, official prerequisite detection,
  isolated browser profile, separate shortcuts, and profile-preserving uninstall.
- Windows Setup EXE and installer ZIP with no external developer dependencies.
